TaraLoom Mobile Interactive Prototype – v11

Open index.html in Chrome/Edge/Safari.

What is interactive:
- 30 sample orders across In Process, Ready and completed History
- Home shows the number of active orders due today
- Add/edit orders, measurements, payments, garment photo, reference images, camera input and sketches
- Separate garment photo can be added while placing the order and viewed/replaced/deleted later
- Simple PNG measurement icons for Bust/Chest, Waist, Hip, Shoulder, Sleeve and Length
- Phone validation: optional, but when entered it must be exactly 10 digits and start with 6, 7, 8 or 9
- Order Detail supports quick editing without leaving the View page
- Add/delete reference images directly from Order Detail
- Sketch on a duplicate of any reference image; the original reference remains unchanged
- Add/delete finished photos and edit/delete an order sketch
- Share order details with finished photos on supported devices
- Profile saves in browser localStorage and remains after refresh
- Language setting is functional: switch between English, Telugu and Hindi from Profile; the interface updates immediately and the choice persists after refresh
- Profile includes Stock Requirements with quantity, notes, bought/needed state, edit and delete
- Profile includes Connection Management for coworkers, partners, Maggam workers, hand-paint artists, handloom artists, crochet artists and others
- Connections can save profession, shop/brand, phone, address and notes
- Tap order/catalog images for full-screen view
- Current Orders and separate History tab
- Customer search and old order history
- Pinterest-style Catalog: upload an image, name it, rename/delete uploaded styles, and share catalog images
- Share order, complete/reopen, recycle bin/restore
- Backup JSON includes profile, orders, catalog, stock requirements and connections

Note: This is a front-end prototype. Data persists locally in the browser/device. A production multi-device real-time app would still need a backend/database and user authentication.
